CodeLab Question Type: Programming Questions Graded with Tests

Students write a program in the code editor of VS Code. It is run on the teacher's tests on a Jobe server, and the grade is the weighted share of the tests it passes.

Live demo: try the CodeLab plugins on codelab.tsp.edu.rs. Look around as a guest (Python runs in the browser), or use the demo accounts teacher and student (password Demo-2026) to run every language, the debugger and SQL. Everything is reset every night.

What's New in v1.5.0

  • Synchronized with CodeLab 1.5.0: automatic dark mode and theme resolution from tiny_codelab.
  • Theme support: students answering coding questions automatically get dark or light Monaco editor matching their system or site preference.

Core features

  • Eight languages: C, C++, Python, Java, C#, JavaScript, Pascal and PHP.
  • Tests: each test has an input, an expected output, a weight, and can be hidden. Students see only how many hidden tests passed. Empty expected outputs are filled in by running the model solution when the question is saved.
  • Hidden code before and after the answer: for example the class and Main around a few statements.
  • For the student: the code editor with typing help, Run with their own input, and Run the tests for the tests that are not hidden.
  • Safe grading: the grade is computed on the server only. Results are cached, so a review or a regrade does not load Jobe again. When Jobe cannot check a program at the final submit, the answer waits for the teacher.
  • Check with penalties in Interactive and Adaptive mode, and output compared exactly, without trailing spaces, as numbers with a tolerance or by a regular expression.
  • Options: time and memory limits, and turning off typing help for tests. A question without tests is graded by the teacher.
  • Backup and restore keep all settings and tests.

The CodeLab plugins

  • CodeLab for TinyMCE: inserts examples in the TinyMCE editor. The other two plugins use its editor and runner.
  • CodeLab filter: turns examples into code editors that readers can edit and run.
  • CodeLab question type (this plugin): programming questions graded on Jobe with tests.

Requirements

  • Moodle: 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • tiny_codelab: version 1.5.0 or newer (1.5.1 for input on phones), installed first, with a Jobe server in its settings.

Privacy

Answers are stored like any quiz answer. Programs and their input are sent to the Jobe server set by the administrator to be compiled and run. The plugin implements the Moodle Privacy API.
